# Keshin2D

<p align="center"><a href="README.md">日本語</a> | <a href="README.en.md">English</a> | <strong>简体中文</strong></p>

Keshin2D 可以让角色立绘在浏览器里动起来。你可以用鼠标或摄像头控制角色，让它跟着你的声音做口型，也可以用一张立绘做出自己的 2D 模型。

**[在浏览器里尝试](https://rotejin.github.io/Keshin2D/)**。无需安装，打开后即可预览效果。左侧面板顶部可以切换两个自带角色。

![Keshin2D 自带的两个角色的演出预览](docs/images/demo.webp)

## 在自己电脑上运行

从仓库页面点 **Code → Download ZIP**，下载后解压。也可以用 `git clone`。进入项目文件夹后，任选一种方式启动。

| 系统 | 怎么启动 |
| --- | --- |
| Windows | 双击 `start.bat` |
| macOS、Linux | 在终端运行 `./start.sh`。如果从 ZIP 解压后没有执行权限，可以用 `sh start.sh` |
| 通用 | 运行 `python tools/serve.py`。有些系统要用 `python3` |

浏览器会自动打开，默认显示 `kurage02`。想直接打开 `chiwa`，可以运行 `start.bat --model chiwa`，在 macOS 或 Linux 上用 `./start.sh --model chiwa`。

启动时出现的终端窗口是本地服务器，使用期间请保持它打开。默认端口是 `8770`，被占用时会向后最多找 20 个端口。也可以用 `--port` 指定端口。直接双击 `index.html` 时，浏览器会阻止页面读取模型文件，请用上面的方式启动。

本地运行需要 **Python 3.8 或更新版本**，无需额外安装 Python 库。浏览器需要支持 **WebGL2**，项目在 Chrome 和 Edge 上验证过，Firefox 和 Safari 尚未验证。Windows 做过实际操作验证。macOS 和 Linux 已在 GitHub Actions 的无界面 Chrome 环境里通过启动、显示和操作检查。检查时没有使用 GPU，也还没在实际桌面环境里手动验证。

## 怎么操作

面板目前是日文。下表保留了按钮上的原文，可以对着找。

| 面板上写的是 | 怎么用 |
| --- | --- |
| 顶部的模型下拉框 | 切换自带模型或自己制作的模型。 |
| `動かし方` | `マウス` 让角色看向鼠标，`カメラ` 让角色跟随你的脸，`おまかせ` 循环播放约 14 秒的自动演出。切回 `マウス` 时，表情也会恢复默认。 |
| `マイクで口パク` | 开启麦克风口型同步。嘴形会随发出的元音变化，右侧的音量条可以用来确认有没有收到声音。 |
| `口パクデモ` | 播放一段无声的说话动画，方便看口型效果。 |
| `表情` | 共 22 种，包含默认表情。上面 8 个可用数字键 `1` 到 `8` 切换，其余在 `ほかの表情` 里。 |
| `背景` | 可以选浅色、深色、白色、绿幕或透明。 |
| `隠す` | 隐藏面板，也可以按 `H` 切换。隐藏后移动鼠标，左上角会出现 `☰` 按钮。 |

在画面里拖动可以移动角色，滚动鼠标滚轮可以缩放，双击可以恢复位置和大小。

### 调整动作和口型

点开 `好みに合わせる`，就可以调整角色的动作幅度。`動きの好み` 可以调身体动作、头发和饰品的摇晃幅度，以及瞳孔的弹动幅度，也可以用 `おちついた`、`ふつう`、`元気` 三个预设直接切换。想单独调耳环或蝴蝶结，就打开 `飾りごとに決める`。

`向きの上限` 里的九个方向按钮，可以让脸停在对应方向的极限位置，边看边调整转头、抬头、低头和歪头的幅度。口型和声音对不上时，可以在 `マイクの口パク` 下点 `声を覚えさせる`，按提示读五个元音。想自己微调嘴形，可以在 `母音の口の大きさ` 里选一个元音，再调张开程度、宽度和上下位置。

`キャラを作る人向け` 里是制作模型时用的详细选项。平时使用，主要看上面两区就够了。设置和画面位置会按模型保存在浏览器里，换端口后会使用另一份设置。要恢复模型默认值，可以点 `好みを全部もとに戻す`。

### 在 OBS 里使用

点面板底部的 `OBS 用の URL をコピー`，把复制到的地址贴到 OBS 的「浏览器」来源里。本地服务器要保持运行。地址里带着当前布局、驱动方式和调节参数，改过设置后需要重新复制一次。

也可以手动填一个最简单的透明背景地址。

```text
http://127.0.0.1:8770/index.html?model=kurage02&ui=0&bg=transparent
```

`ui=0` 隐藏面板，`bg=transparent` 使用透明背景。宽高按你的 OBS 场景来设。

项目还没有在 OBS 里实际测试过，包括鼠标跟随、摄像头和麦克风。如果浏览器来源效果不理想，可以在普通浏览器里用 `bg=green` 打开，再在 OBS 里捕获窗口并扣掉绿幕。

### URL 参数

参数加在 `index.html?` 后面，多个参数用 `&` 连接。

| 参数 | 示例 | 用途 |
| --- | --- | --- |
| `model` | `model=chiwa` | 指定 `models/` 下的模型文件夹，默认是 `kurage02`。 |
| `hair` | `hair=0` | 隐藏头发，方便检查脸部。 |
| `ui` | `ui=0` | 隐藏操作面板。 |
| `bg` | `bg=transparent` | 设置背景，可用 `room`、`dark`、`white`、`green`、`transparent`。 |
| `mode` | `mode=demo` | 设置驱动方式，可用 `mouse`、`camera`、`demo`。 |
| `exp` | `exp=笑顔` | 固定在指定表情，参数值用界面上的日文表情名。 |
| `yaw`、`pitch`、`roll` | `yaw=20` | 固定头部的转向、俯仰或倾斜角度，单位是度。 |
| `cx`、`cy`、`zoom` | `zoom=2&cy=800` | 指定画面中心和缩放，覆盖保存的布局。 |

制作用面板里的滑块也可以通过参数设置，例如 `yawMax=25`。参数名见 `js/avatar.js` 里的 `PARAMS` 和 `TUNE`。复制 OBS 地址时会生成 `set=`，用来一次传入多项设置。

## 自带的两个模型

| 模型 | 可以看什么 |
| --- | --- |
| `kurage02`（クラゲちゃん） | 默认打开的角色。水母帽、发饰和胸前的蝴蝶结会跟着动作摇晃。 |
| `chiwa`（チワちゃん） | 头顶翘起的发束和耳环会摇晃。这个模型是用仓库里的工具和流程，从一张角色图做出来的。 |

两套模型放在 `models/`。制作时用的配置、图像生成提示词和笔记放在 `partsgen/chars/`。想知道一张图实际是怎么做成模型的，可以看 `chiwa` 的制作记录，里面也记了中途踩过的坑。 [制作记录（日文）](partsgen/chars/chiwa/NOTES.md)

## 用一张图做自己的角色

准备一张你有权使用的角色图。Codex CLI 会根据原图重新绘制各个部件，仓库里的工具负责把它们裁出来、放回对应的位置，再导出模型。

1. **准备环境。** 需要 Python 3.10 或更新版本，以及 `numpy`、`opencv-python`、`pillow`，还需要 Node.js 22 或更新版本、支持生成图片的 Codex CLI、Real-ESRGAN，以及 Claude Code 之类的 AI 编程助手。Real-ESRGAN 需要支持 Vulkan 的 GPU，按准备文档里的命令可以从发布方下载。图像生成验证用的是 Windows 版 Codex 应用附带的 CLI，使用时需要相应的 OpenAI 套餐。 [准备步骤（日文）](partsgen/README.md)
2. **把图片交给助手。** 在项目目录打开 AI 编程助手，把 `partsgen/MASTER_PROMPT.md` 的提示词发给它。只需要改两行，填上图片路径和角色名称。名称用英文字母和数字。 [制作提示词（日文）](partsgen/MASTER_PROMPT.md)
3. **在几个关键地方亲自看一下。** 助手会停下来让你确认底图像不像原角色、要用哪版头发，以及角色动起来是否自然。看到哪里不舒服，直接描述就行，比如「耳环看起来要掉了」。

导出的模型会放在 `models/<name>/`，可以在面板顶部选，也可以用 `start.bat --model <name>` 打开。

制作工具目前只在 Windows 上验证过。现有角色是在流程不断调整的过程中做出来的，整理后的流程还没有单独拿一个新角色从头跑过。生成的图片每次也会有差别，最后的动作效果建议自己拖动鼠标、切几次表情看看。 [完整制作流程（日文）](partsgen/WORKFLOW.md)

## 遇到问题

| 现象 | 可以先检查什么 |
| --- | --- |
| Windows 提示「Windows 已保护你的电脑」 | 解压前，右键点 ZIP，打开「属性」，勾选「解除锁定」后重新解压。 |
| 提示 `Python 3.8 or later was not found.` | 安装 Python 3.8 或更新版本，然后重新运行 `start.bat`。 [下载 Python](https://www.python.org/downloads/) |
| 页面空白，或一直显示 `画像を読み込み中…` | 确认地址栏不是 `file:///` 开头，本地服务器还开着。如果显示 `WebGL2 が使えません`，试试 Chrome 或 Edge。 |
| 摄像头没反应 | 检查地址栏旁的摄像头权限。如果面板提示 `カメラを開始できませんでした`，也看看摄像头有没有被其他应用占用。 |
| 开了麦克风，嘴还是不动 | 先看浏览器的麦克风权限。音量条有反应但嘴张得很小，可以在 `好みに合わせる` → `マイクの口パク` 里调大。 |
| 想撤销调节 | 点 `好みを全部もとに戻す`。如果只想把画面的位置和大小调回去，双击画面即可。 |
| 自己做的模型没出现在列表里 | 确认有 `models/<name>/model.json`。本地服务器会自动发现模型。如果部署在 GitHub Pages 之类的静态站点上，要把模型名加进 `models/index.json`。 |
| Linux 上日文显示成方块 | 安装支持日文的字体，例如 Noto Sans CJK。Ubuntu 或 Debian 可以运行 `sudo apt install fonts-noto-cjk`。 |

目前还有几个已知问题。`chiwa` 往斜下方转到最大角度时，远侧眼睛会稍微越过脸部轮廓。`kurage02` 往斜上方看时，近侧耳朵会显得偏大。摄像头跟踪和麦克风口型已用测试视频和音频验证过，真人使用时的跟随效果还有待进一步验证。

## 更新和反馈

用 Git 下载的，先关掉本地服务器，运行 `git pull`，然后重新启动。用 ZIP 下载的，把新版解压到另一个文件夹，再把旧目录里自己的 `models/<name>/` 和 `partsgen/chars/<name>/` 复制到对应位置。调过的参数保存在浏览器里。想清掉这些参数，可以清除对应站点的数据。

遇到问题可以按模板开 Issue。安全漏洞请按仓库的安全说明私下报告。其他事项也可以在 X 上联系作者。 [提交 Issue](https://github.com/rotejin/Keshin2D/issues/new/choose) · [安全说明](.github/SECURITY.md) · [@rotejin](https://x.com/rotejin)

## 隐私

摄像头画面和麦克风声音都在浏览器里处理，查看器不会录制或上传。人脸跟踪用的 MediaPipe 已经随项目一起提供，可以离线运行。调节参数和画面布局保存在当前浏览器里。

## 名称和许可证

Keshin 来自日语「化身」（けしん）。Keshin2D 使用自己的模型格式，无法加载 Live2D 模型。本项目与 Live2D、OpenAI、Anthropic 或 Google 无官方隶属关系。
